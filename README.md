# Research Data & Code Repositories

An index of the public datasets, software and trained models cited in the data and code availability statements of publications co-authored by Mathias B. Steiner (2021–2026), in four research lines: quantum-centric materials simulations, materials discovery for MOFs and polymers, geoscience and digital rock, and digital agriculture. Each entry links to the repository and to the paper it supports, and has a QR code that opens the repository directly.

The page is published with GitHub Pages from `index.html`.

## What this page is, and isn't

- It only links to and describes repositories hosted elsewhere. It does not copy, host or redistribute their code or data.
- Each repository belongs to its owner (the account or authors that published it) and is governed by its own licence. Licence labels were checked against each repository's licence file or record in October 2026. Always read the licence in the repository itself before reuse.
- Listing a repository does not imply that its owner, the authors' institutions or any other party endorses this page, or that any of them owns repositories held by others.

## Privacy

The page uses no cookies, analytics, web fonts or other third-party resources. Visiting it sends no data anywhere except GitHub Pages.
